Проект автоматически пересобирается и публикуется при каждом push в ветку main.  
  
Если необходимо запустить сборку вручную (без создания нового коммита):  
  
Перейдите во вкладку Actions приватного репозитория.
Выберите workflow с названием Deploy to Public Pages Repository в левом меню.
Нажмите кнопку Run workflow справа от него.
Подтвердите выбор ветки (main) и нажмите Run workflow ещё раз.
После завершения сборки проект будет опубликован на GitHub Pages.
  
Ссылка на сайт: https://angelina1607.github.io/mesto-production/
